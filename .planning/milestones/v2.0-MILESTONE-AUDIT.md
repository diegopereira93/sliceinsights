### Critical Defect

**`slo_validator.py:check_freshness()` — missing `pass` branch**

```python
# Current (lines 113–118):
if age_hours < FRESHNESS_SLO_HOURS:
    status = "skip"   # within SLO → skip, not pass
else:
    status = "fail"   # stale → fail
# No branch emits status = "pass"
```

`deploy_worker.py:check_slo_gate()` queries `slo_logs WHERE status='pass' AND scraper_name != '__all__'`.

- Freshness entries: never `pass` — always excluded
- Completeness entries: `pass` only for `__all__` — excluded by `!= '__all__'` filter

**Result:** Nightly deploy aborts with *"No scrapers passed SLO gate"* on every run.
**Affected:** SLO-03, DEP-01

**Fix:** Add `status = "pass"` branch to `check_freshness()` when `age_hours < FRESHNESS_SLO_HOURS`. Possibly also reconsider whether `completeness` `pass` rows should use `scraper_name` (not `__all__`).
