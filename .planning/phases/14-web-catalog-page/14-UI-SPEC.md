## Typography

Two weights only: 400 (body) and 700 (all non-body text).

| Role | Size | Weight | Line Height | Tailwind Class | Usage |
|------|------|--------|-------------|----------------|-------|
| Body | 14px | 400 | 1.5 | `text-sm font-normal` | Card price, badge labels, filter option text |
| Label | 12px | 700 | 1.3 | `text-xs font-bold` | Brand badge, thickness badge, filter section headings (uppercase tracking-wider) |
| Heading | 16px | 700 | 1.4 | `text-base font-bold` | Paddle model name on card, page section title |
| Display | 20px | 700 | 1.2 | `text-xl font-bold` | Page heading "Catálogo de Raquetes" |

Font: Inter via `var(--font-inter)`. Dark-mode-first — all text on `bg-background (#000000)`.

Accent (`#ceff00`) reserved for:
1. Active/selected filter badge fill
2. Card hover ring (`hover:ring-2 hover:ring-primary/30`)
3. "Ver na [Loja]" CTA button background (with `foreground: #000000` text)
4. Price "A partir de R$" value text
5. Focus ring on interactive elements (`ring-ring`)

Accent is NOT used for: inactive badges, body text, backgrounds, borders, skeleton cards.

## Interaction Contract

### Filter Behaviour

| Trigger | Action | Debounce |
|---------|--------|----------|
| Any filter change | Update URL params (shallow router.replace) + set isLoading=true | 400ms before fetch fires |
| Filter cleared (X on chip) | Remove param from URL + re-fetch | 400ms |
| Drawer close | No additional fetch (fetch already fired on change) | — |
| Page load with URL params | SSR initial fetch in Server Component reads searchParams | None (SSR) |

### Pagination

- Page size: 24 paddles per page (`limit=24`)
- URL param: `?page=2` (maps to `offset = (page-1) * 24`)
- Page change fires immediate fetch (no debounce — explicit user action)
- "Anterior" button disabled on page 1; "Proxima" disabled when `offset + limit >= total`

### Filter Drawer

| Filter | Control | Values |
|--------|---------|--------|
| Espessura | Badge toggle (single select) | "14mm" / "16mm" / "Todas" |
| Material da face | Badge toggle (single select) | "Carbon" / "Fiberglass" / "Todos" |
| Preço | Range slider (R$0–R$4000) | Continuous, shows live value labels |
| Marca | Text input + badge list (single select per Pitfall 5) | Type-ahead search, clear button |
| Loja | Badge toggle list | One badge per store from `/catalog/stores`, + "Todas" |

Active filter count badge appears on "Filtros" button when ≥ 1 filter is active.

### Loading State Transitions

```
idle          → user changes filter → isLoading=true  → skeleton cards shown
isLoading     → fetch resolves      → isLoading=false → real cards animate in (framer-motion)
isLoading     → fetch errors        → isLoading=false → error state shown
fetch success → total === 0         → empty state shown
```

Card entrance animation (framer-motion):
```typescript
initial={{ opacity: 0, y: 20 }}
animate={{ opacity: 1, y: 0 }}
transition={{ duration: 0.3, delay: index * 0.05 }}
```

| Error state body | "Não foi possível conectar ao servidor. Tente novamente." | Button: "Tentar novamente" |

| Pagination next | "Proxima" | Disabled state: same |
