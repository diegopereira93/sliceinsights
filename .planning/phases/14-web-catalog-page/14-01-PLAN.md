Structure (exact classes from UI-SPEC Card Anatomy):

- Image area: `<div className="aspect-[4/5] overflow-hidden">` containing `<img src={paddle.image_url ?? '/placeholder-paddle.png'} alt={paddle.model_name} loading="lazy" className="object-cover w-full h-full" />`

- Content area: `<div className="p-4 space-y-2">`
  - Badges row: `<div className="flex gap-2 flex-wrap">`

  - Model name: `<h3 className="text-base font-bold text-foreground leading-tight">{paddle.model_name}</h3>`
  - Price: `<p className="text-sm text-muted-foreground">A partir de <span className="text-primary font-bold">R$ {cheapestOffer.price_brl.toLocaleString('pt-BR')}</span></p>` where `cheapestOffer = paddle.market_offers[0]` (API returns sorted asc by price_brl)
    - If no offers, show nothing for price area
  - CTA button: `<a href={cheapestOffer.store_url} target="_blank" rel="noopener noreferrer">` wrapping `<Button size="sm" className="w-full rounded-xl font-bold text-xs bg-primary text-primary-foreground">` with `<ExternalLink className="w-3.5 h-3.5 mr-1.5" />` icon and text `Ver na {cheapestOffer.store_name}`
