    **GET /catalog/paddles endpoint** (`list_catalog_paddles`):
    - Query params:
      - `core_thickness: Optional[List[float]] = Query(default=None)` — multi-value, OR logic via `IN()`
      - `surface_material: Optional[List[FaceMaterial]] = Query(default=None)` — multi-value, OR logic via `IN()`
      - `price_min: Optional[float] = None`
      - `price_max: Optional[float] = None`
      - `brand: Optional[str] = None`
      - `store: Optional[str] = None` — matches `Store.slug`
      - `limit: int = Query(default=50, le=100, ge=1)`
      - `offset: int = Query(default=0, ge=0)`
    - Rate limit: `@limiter.limit("100/minute")`
    - Build offer subquery: aggregate `min(MarketOffer.price_brl)` per `paddle_id` WHERE `is_active == True`, grouped by `paddle_id`
    - Main query: `select(PaddleMaster, offer_subq.c.min_price)` with:
      - `selectinload(PaddleMaster.brand)`
      - `selectinload(PaddleMaster.market_offers).selectinload(MarketOffer.store)` — CRITICAL: chain to load store via relationship
      - INNER JOIN on offer subquery (intentionally excludes paddles with no active offers — CAT-06)
      - Default order: `offer_subq.c.min_price.asc()` (cheapest first)
    - Apply filters WHERE clauses:
      - `core_thickness`: `PaddleMaster.core_thickness_mm.in_(core_thickness)` — direct scalar column on PaddleMaster, NOT a JSON field
      - `surface_material`: `PaddleMaster.face_material.in_([m.value for m in surface_material])` — compare against enum .value strings
      - `price_min`: `offer_subq.c.min_price >= price_min`
      - `price_max`: `offer_subq.c.min_price <= price_max`
      - `brand`: Join `Brand` table, `Brand.name.ilike(f"%{brand}%")`
      - `store`: Join `MarketOffer` then `Store`, filter `Store.slug == store`
    - NOTE on store filter: When applying the store filter, be careful not to duplicate JOINs. The offer subquery already joins MarketOffer implicitly. The store filter needs an explicit JOIN path: `.join(MarketOffer, PaddleMaster.id == MarketOffer.paddle_id).join(Store, MarketOffer.store_id == Store.id).where(Store.slug == store)`. Only add these JOINs when the store filter is present.
    - Count query: separate `select(func.count()).select_from(...)` with same filters but no limit/offset
    - Build response: for each `(paddle, min_price)` row:
      ```python
      {
          "id": str(paddle.id),
          "brand": paddle.brand.name if paddle.brand else None,
          "model_name": paddle.model_name,
          "specs": {
              "core_thickness_mm": paddle.core_thickness_mm,
              "surface_material": paddle.face_material.value if paddle.face_material else None,
          },
          "market_offers": [
              {
                  "store_name": o.store.name,   # via selectinload — NOT o.store_name
                  "price_brl": float(o.price_brl),
                  "store_url": o.url,
              }
              for o in sorted(
                  [o for o in paddle.market_offers if o.is_active],
                  key=lambda x: x.price_brl
              )
          ],
      }
      ```
    - Return envelope: `{"data": [...], "total": total, "limit": limit, "offset": offset}`

    **GET /catalog/stores endpoint** (`list_catalog_stores`):

    - Brand filter: `query.where(brand == any_(Store.available_brands))` — uses PostgreSQL ARRAY `any_()` operator

          "is_active": s.is_active,

    - Return envelope: `{"data": [...], "total": len(stores)}`
