  <action>
    Create `scripts/deploy_validator.py` with the following functions:

    1. `check_slo_gate(session: Session, batch_date: date) -> tuple[list[str], list[str]]`:
       - Queries `slo_logs` table for entries where `checked_at` is within the calendar day (`batch_date 00:00:00 UTC` to `batch_date 23:59:59 UTC`)
       - Groups by scraper_name, checks if ALL metrics for each scraper have status="pass"
       - Returns (passed_scrapers: list[str], failed_scrapers: list[str])
       - SQL: `SELECT DISTINCT scraper_name FROM slo_logs WHERE checked_at >= :day_start AND checked_at < :day_end AND status = 'pass' AND scraper_name != '__all__'`
       - Also get failed: `SELECT DISTINCT scraper_name FROM slo_logs WHERE checked_at >= :day_start AND checked_at < :day_end AND status = 'fail' AND scraper_name != '__all__'`

    2. `run_corruption_audit(session: Session, batch_id: str) -> tuple[bool, list[str]]`:
       - Checks `market_offers_staging` for rows with `batch_id = :batch_id`:
         a. Count total rows. If 0: return (False, ["Empty batch: no rows in staging for batch_id"])
         b. Count rows where `price_brl IS NULL`: if > 0, append failure
         c. Count rows where `url IS NULL`: if > 0, append failure
         d. Count rows where `store_name IS NULL`: if > 0, append failure
         e. Count rows where `paddle_id IS NULL`: if > 0, append failure
       - Returns (len(failures) == 0, failures)
       - Use `sync_engine` from `app.db.database` for all queries

    3. `run_pre_deploy_validation(batch_id: str, batch_date: date) -> tuple[bool, list[str]]`:
       - Creates a Session from sync_engine
       - Calls check_slo_gate(session, batch_date) — if failed_scrapers non-empty, append failure reasons
       - Calls run_corruption_audit(session, batch_id) — append any corruption failures
       - Returns (all_passed, all_failures)

    4. CLI entry point (`if __name__ == "__main__"`):
       - `--validate-batch BATCH_ID` — runs full validation for given batch_id
       - `--batch-date YYYY-MM-DD` — optional, defaults to today UTC
       - Prints results and exits with code 0 (pass) or 1 (fail)
       - Uses argparse following same pattern as alert_worker.py

    Import pattern: `from sqlalchemy import text`, `from sqlalchemy.orm import Session`, `from app.db.database import sync_engine`
