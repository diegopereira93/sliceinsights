<decisions>
## Implementation Decisions

### Root Cause: Stale `.next` Build (Docker)

The `.next` directory was built by the Docker container (root-owned files). The dev server generates new JS chunk IDs but the old files are locked (permission denied). Result: `main-app.js`, `layout.js`, and other core chunks return 404 → client-side hydration fails → Overview tab content does not render.

**Fix**: Rebuild the Docker frontend container to get a fresh `.next` build:
```bash
docker compose build frontend && docker compose up -d frontend
```

### Pending Changes to Commit (3 files)

These are valid improvements sitting uncommitted:

1. **`frontend/components/statistics-client.tsx`** — 2 changes:
   - Line 270: `getTop('powerOriginal', ...)` → `getTop('power', ...)` — corrects field name for leaderboard (the `power` field is the normalized value; `powerOriginal` is the raw value still used for `topPowerPaddle` display)
   - Lines ~592, 664, 736, 788: Charts in Comparativos section add `activeTab === 'comparativos' &&` condition — prevents unnecessary rendering when user is on a different tab (performance optimization)

2. **`frontend/components/statistics/brand-intelligence.tsx`** — Line 154: filter `count >= 2` → `count >= 1` — shows brands with at least 1 paddle (necessary for small datasets where brands may have only 1 entry)

3. **`frontend/tsconfig.json`** — Adds `.next-clean/types/**/*.ts` to `include` array — supports a `.next-clean` parallel build path

All 3 changes are safe to commit as-is.

### Verification After Rebuild

After rebuild, verify via playwright:
- `/statistics` Overview tab shows paddle cards and leaderboards
- `/statistics` Comparativos tab shows scatter charts when active
- Zero console 404 errors for `_next/static/chunks/`
