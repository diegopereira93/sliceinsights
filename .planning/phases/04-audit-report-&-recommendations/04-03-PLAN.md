## Manual Execution Guide

### How to Run a Scraper

Standard command format for all scrapers:

```bash
docker compose exec -T backend_v3 python scripts/<scraper_name>.py
```

- `-T` flag: disables TTY allocation (required for non-interactive execution, e.g., cronjobs)
- `backend_v3`: the Docker service containing the scraper scripts and database access

## Troubleshooting

### Common Issues

| Symptom | Likely Cause | Fix |
|---------|-------------|-----|
| `playwright._impl._api_types.Error: ... chromium` | Chromium not installed | `playwright install chromium` |
| `error: the following arguments are required: --csv` | CSV ingester run without argument | Provide `--csv <path>` |
| Exit 0 but 0 products scraped | CSS selector changed, DNS issue, or empty catalog | Check store URL manually; verify product count in production |
| `psycopg2.OperationalError: connection refused` | PostgreSQL not running | `docker compose up -d` |
| `ModuleNotFoundError` | Python dependency not installed | `docker compose exec backend_v3 pip install <module>` |
