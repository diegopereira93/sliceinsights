       - `upsert_alert_record(session: Session, scraper_name: str, metric_type: str) -> None`
         Select existing record by scraper_name + metric_type. If exists, update last_alert_time to now UTC, increment alert_count, set updated_at. If not exists, create new SLOAlert with status="active", alert_count=1.
       - `clear_alert_throttle(session: Session, scraper_name: str, metric_type: str) -> None`

       class SLOAlertService:
           def __init__(

               github_token: str = "",
               github_repo: str = "",
               email_host: str = "",

       Methods:
       - `notify(self, breach: SLOBreach) -> dict[str, bool]`:
         Get channels via `_get_channels_for_severity(breach.severity)`. For each channel, call `_send(channel, breach)` in try/except. Log warning on failure. Return `{"telegram": True/False, "github": True/False, "email": True/False}`.

       - `_get_channels_for_severity(self, severity: str) -> list[str]`:
         P1 -> ["telegram", "github", "email"]; P2 -> ["telegram", "github"]; else -> []

       - `_send(self, channel: str, breach: SLOBreach) -> bool`:
         Dispatch to `_send_telegram`, `_create_or_update_github_issue`, or `_send_email`.

       - `_send_telegram(self, breach: SLOBreach) -> bool`:
         If no token or chat_id, return False. Format message using Markdown (v1, same as price_alerts.py):
         ```
         {icon} *SLO Breach -- {severity}*

         *Scraper:* {scraper_name}
         *Metric:* {metric_type}
         *Age:* {value_hours:.1f}h (threshold: {threshold_hours:.0f}h)
         *Last data:* {last_record_time or 'unknown'}
         *Detected:* {checked_at}

         [Runbook]({runbook_url})
         ```
         Icon: P1 = "\U0001f6a8" (siren emoji), P2 = "\u26a0\ufe0f" (warning emoji).
         POST to `https://api.telegram.org/bot{token}/sendMessage` with `parse_mode=Markdown`, timeout=15. Return resp.ok.

       - `_create_or_update_github_issue(self, breach: SLOBreach) -> bool`:
         If no github_token or github_repo, return False.
         Use `Github(auth=Auth.Token(self.github_token))` (PyGithub 2.x pattern).
         Get repo via `g.get_repo(self.github_repo)`.
         Title: `[{severity}] {scraper_name} SLO Breach: {metric_type}`
         Body: Include timestamp, value_hours, threshold_hours, last_record_time, remediation steps, runbook link.
         Labels: `["slo-breach", "p1-critical"]` for P1, `["slo-breach", "p2-important"]` for P2.
         Search open issues: `repo.get_issues(state="open", labels=["slo-breach"])`. If any issue.title matches our title exactly, call `issue.edit(body=body)` and return True. Else `repo.create_issue(title=title, body=body, labels=labels)` and return True.

       - `_send_email(self, breach: SLOBreach) -> bool`:
         If no email_host or email_user or admin_email_group, return False.
         Parse recipients: `self.admin_email_group.split(",")` and strip whitespace.
         Subject: `[ALERT] {scraper_name} freshness SLO breach`
         Build EmailMessage with plain text body containing scraper_name, metric_type, value_hours, threshold_hours, checked_at, last_record_time, runbook URL.
         Send via `smtplib.SMTP(email_host, email_port)` -> `ehlo()` -> `starttls(context=ssl.create_default_context())` -> `login(user, password)` -> `send_message(msg)`. Return True.
