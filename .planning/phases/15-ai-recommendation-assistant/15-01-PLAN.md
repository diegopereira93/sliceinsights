**Endpoint `POST /recommend`** (`post_recommendations`):
- Decorator: `@router.post("", response_model=RecommendationResult)` + `@limiter.limit("30/minute")`
- Parameters: `request: Request`, `body: RecommendationRequest`, `session: AsyncSession = Depends(get_session)`
- Build `UserProfile` from body: `UserProfile(skill_level=body.skill_level, budget_max_brl=body.budget_max_brl, play_style=body.play_style, has_tennis_elbow=body.has_tennis_elbow, spin_preference=body.spin_preference, weight_preference=body.weight_preference, power_preference_percent=body.power_preference_percent)`
- Instantiate engine: `engine = RecommendationEngine(session)`
- Call: `result = await engine.get_recommendations(profile, limit=body.limit, use_ai_ranking=True)`
- If `result.recommendations` is not empty, enrich with market_offers:
  - Collect `paddle_ids = [r.paddle_id for r in result.recommendations]`
  - Query paddles with selectinload: `select(PaddleMaster).options(selectinload(PaddleMaster.market_offers).selectinload(MarketOffer.store)).where(PaddleMaster.id.in_(paddle_ids))`
  - Build lookup: `paddles_map = {p.id: p for p in (await session.exec(stmt)).all()}`
  - Get affiliate service: `affiliate = get_affiliate_service()`
  - For each recommendation in `result.recommendations`:
    - Get paddle from map: `paddle = paddles_map.get(rec.paddle_id)`
    - If paddle found, set `rec.image_url = paddle.image_url`
    - Build `rec.market_offers` from `paddle.market_offers` where `o.is_active`, sorted by `price_brl` ASC:
      ```python
      rec.market_offers = sorted(
          [MarketOfferOut(
              store_name=o.store.name,
              price_brl=float(o.price_brl),
              store_url=affiliate.transform_url(o.url, store_name=o.store.name),
          ) for o in paddle.market_offers if o.is_active],
          key=lambda x: x.price_brl,
      )
      ```
- If `len(result.recommendations) == 0` (no-match path after engine's own fallback):
  - Call `no_match_dossier = await llm_service.generate_dossier(user_profile=profile.model_dump(), top_paddles=[])`
  - Set `result.grok_dossier = no_match_dossier`
- Return `result`

**Endpoint `POST /recommend/chat`** (`post_chat`):
- Decorator: `@router.post("/chat", response_model=ChatResponse)` + `@limiter.limit("60/minute")`
- Parameters: `request: Request`, `body: ChatRequest`
- Convert messages: `messages = [{"role": m.role, "content": m.content} for m in body.messages]`
- Call: `reply = await llm_service.chat_with_context(chat_history=messages, context=body.context)`
- Return `ChatResponse(reply=reply)`
