Present the user with the verification checklist below. The user must manually test the full flow in a browser.

What was built: Complete AI Recommendation Assistant — 3-step player profile wizard at /recommend, API endpoints POST /api/v1/recommend and POST /api/v1/recommend/chat, result cards with purchase links, and inline AI chat panel.

How to verify:

**Prerequisites:** Ensure the backend is running (`uvicorn app.main:app --reload`) and the frontend dev server is running (`cd frontend && npm run dev`).

**Test 1 — Wizard Flow (REC-01):**
1. Navigate to the catalog page in the browser
2. Verify the CTA banner "Nao sabe qual raquete?" appears
3. Click the CTA to go to /recommend
4. Complete Step 1: select "Intermediario" and "Equilibrado"
5. Complete Step 2: enter budget 2000 (or click "Sem limite")
6. Complete Step 3: leave tennis elbow off, select weight "Sem preferencia"
7. Click "Ver Recomendacoes"
8. Verify: Loading skeletons appear, then 3 recommendation cards render

**Test 2 — Result Cards (REC-02):**
1. First card should have "Match Perfeito" badge with lime accent border
2. Each card should show: paddle image (or placeholder), brand name, model name
3. Each card should have at least one store link with price in BRL
4. Click a "Comprar" link — verify it opens the store page (may have affiliate UTM params)

**Test 3 — Chat (REC-01 + REC-02):**
1. Chat panel should auto-open below the cards
2. First message (from assistant) should be the LLM dossier mentioning the recommended paddles
3. Type "Qual a diferenca entre a primeira e a segunda?" and send
4. Verify: LLM responds with relevant comparison based on the 3 recommended paddles
5. Verify the LLM does NOT hallucinate stores or specs not present in the context

**Test 4 — No-match scenario (REC-01 criteria 4):**
1. Go back to the wizard (refresh /recommend)
2. Select "Avancado", "Potencia", budget 100 (very low)
3. Submit
4. Verify: If no paddles match, the page shows a friendly message (not an error or blank screen)

**Test 5 — Rate limiting:**
1. Rapidly submit the wizard 5+ times in quick succession
2. Verify: Eventually shows "Limite de requisicoes atingido" message (not a crash)
