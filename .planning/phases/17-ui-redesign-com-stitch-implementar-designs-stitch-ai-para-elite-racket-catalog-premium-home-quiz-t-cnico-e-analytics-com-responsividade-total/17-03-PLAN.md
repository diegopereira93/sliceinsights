    **Step 1: Rewrite Dockerfile.frontend**
    Replace entire contents with a two-stage Vite + nginx build:

    ```dockerfile
    # Stage 1: Build the Vite SPA
    FROM node:20-alpine AS builder
    WORKDIR /app

    COPY frontend-vite/package.json frontend-vite/package-lock.json* ./
    RUN npm ci

    COPY frontend-vite/ .
    ARG VITE_API_URL=http://localhost:8002
    ENV VITE_API_URL=${VITE_API_URL}
    RUN npm run build

    # Stage 2: Serve with nginx
    FROM nginx:alpine AS runner
    COPY --from=builder /app/dist /usr/share/nginx/html
    COPY frontend-vite/nginx.conf /etc/nginx/conf.d/default.conf
    EXPOSE 80
    CMD ["nginx", "-g", "daemon off;"]
    ```

    Key points:
    - Uses `frontend-vite/` as build context (not `frontend/`)
    - VITE_API_URL is a build-time ARG (Vite embeds env vars at build time via `import.meta.env`)
    - nginx serves static files with SPA fallback from `nginx.conf`
    - No Node.js runtime in production (just nginx)

    **Step 2: Update docker-compose.yml**
    Find the existing frontend service (likely named `frontend_next` or `frontend`) and replace it:

    1. Rename service to `frontend_vite`
    2. Update build config:
       ```yaml
       frontend_vite:
         build:
           context: .
           dockerfile: Dockerfile.frontend
           args:
             VITE_API_URL: http://backend_v3:8000
         container_name: picklematch_ui_vite
         ports:
           - "3002:80"
         depends_on:
           - backend_v3
         networks:
           - picklematch_v3
         restart: unless-stopped
       ```
    3. Preserve the exact same `networks` and `depends_on` as the original frontend service
    4. Ensure the `VITE_API_URL` arg points to the backend container URL (likely `http://backend_v3:8000` or whatever the internal Docker network URL is — check the existing docker-compose.yml for the correct backend service name and port)
    5. If `docker-compose.prod.yml` exists with a separate frontend override, update it similarly

    **Step 3: Ensure CORS allows port 3002**
    Read `app/config.py` and check `allowed_origins` list. If `http://localhost:3002` is not present, add it. The list typically looks like:
    ```python
    allowed_origins = [
        "http://localhost:3000",
        "http://localhost:3001",
        "http://localhost:3002",  # Vite dev server
        ...
    ]
    ```
    If it already includes `http://localhost:3002`, no change needed.

    **Step 4: Verify docker build works**
    ```bash
    docker compose build frontend_vite
    ```
