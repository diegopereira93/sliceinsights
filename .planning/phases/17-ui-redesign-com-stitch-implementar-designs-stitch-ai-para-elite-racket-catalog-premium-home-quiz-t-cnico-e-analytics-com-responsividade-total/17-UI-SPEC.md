## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline chip padding (`px-1 py-0.5`) |
| sm | 8px | Component internal gaps (`gap-2`), filter pill spacing |
| md | 16px | Default element spacing, card content padding (`p-4`) |
| lg | 20px | Card content padding (`p-5`), chart margins |
| xl | 24px | Section padding (`py-6`), KPI grid gaps |
| 2xl | 32px | Page top padding (`pt-8`) |
| 3xl | 48px | Hero bottom padding, major section breaks (`pb-32` = 128px for BottomNav clearance) |

Exceptions:
- Bottom clearance for fixed BottomNav: `pb-32` (128px) on all page root elements — ensures content is not obscured
- Touch targets for BottomNav items: minimum 44px tall (`py-2` within `p-2` container)
- Hero headline uses `clamp(3.2rem, 8vw, 6rem)` fluid sizing — not a fixed token
- Scrollbar width: 8px (custom scrollbar styling)

Source: `Home.tsx`, `Stats.tsx`, `Chat.tsx`, `BottomNav.tsx`

## Typography

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Body | 14px (text-sm) | 400 (regular) | 1.5 | Inter | Card subtitles, filter pill labels, meta text |
| Body-md | 16px (text-base) | 400 (light/regular) | 1.625 (leading-relaxed) | Inter | Hero subheadline, paragraph copy |
| Label | 10px (text-[10px]) | 700 (bold) | 1 | Inter | Brand name above paddle name, stat bar labels (PWR/CTRL/SPIN), eyebrow badges — `tracking-widest uppercase` |
| Heading | 20px (text-xl) | 700 (bold) | 1.25 | Outfit (font-display) | Page section headings, card names (`text-lg`/`text-xl`) |
| Display | fluid clamp(3.2rem → 6rem) | 900 (font-black) | 0.92 | Outfit (font-display) | Hero h1 — `tracking-[-0.03em] italic` for accent word |
| Mono | 10–12px (text-xs/text-[10px]) | 400 | 1 | system monospace (font-mono) | Loading terminal text, Stats page subtitle, chat latency readout — `tracking-widest uppercase` |

Rules:
- All headings (`h1`–`h6`) use `font-display tracking-tight` (from `@layer base`)
- Body text uses `font-sans antialiased`
- Terminal/data labels use `font-mono` for numeric readouts
- `tracking-[0.2em]` applied to eyebrow/status badges; `tracking-widest` on micro-labels

Source: `index.css` `@layer base`, `Home.tsx`, `PaddleCard.tsx`, `Stats.tsx`, `Chat.tsx`

## Color

| Role | CSS Variable | Resolved Value | Usage |
|------|-------------|----------------|-------|
| Dominant (60%) | `--background` | `hsl(240 5% 4%)` — zinc-950 ~`#0a0a0c` | Full-page background, hero mesh gradient base |
| Secondary (30%) | `--card` / `--secondary` | `hsl(240 5% 8%)` — zinc-900 ~`#121214` | Cards (`glass-card`), popover, nav glass panel |
| Muted surfaces | `--muted` / `--border` | `hsl(240 4% 16%)` — zinc-800 ~`#27272a` | Stat bars background, input borders, dividers |
| Accent (10%) | `--primary` / `--accent` | `hsl(74 89% 55%)` — lime-400 `#a3e635` | (see reserved list below) |
| Muted text | `--muted-foreground` | `hsl(240 5% 65%)` — zinc-400 `#a1a1aa` | Secondary body copy, filter pill inactive labels |
| Destructive | `--destructive` | `hsl(0 62% 30%)` — dark red ~`#6b1515` | Destructive actions only (no destructive actions in this phase) |

Accent (`#a3e635` / lime-400) reserved for:
- Active filter pill background + shadow glow
- Active BottomNav icon color + active indicator bar
- CTA primary button background (`bg-primary text-black`)
- Hero headline gradient word ("QUADRA.")
- Brand label above paddle name in PaddleCard (`text-primary`)
- "JOIA RARA" badge gradient (from primary to emerald-400)
- Hidden gem glow in hero area
- Stats KPI highlight card border + icon background
- Recharts bar fill in brand market share chart
- Chat AI avatar border glow + "ONLINE" status dot
- `--ring` focus ring on all focusable inputs
- Scrollbar thumb hover state

Glassmorphism utilities (declared in `index.css`):
- `.glass-panel`: `bg-zinc-950/60 backdrop-blur-xl border border-white/5 shadow-2xl` — used for BottomNav, Chat top bar
- `.glass-card`: `bg-zinc-900/80 backdrop-blur-md border border-white/10 hover:border-primary/50 transition-colors duration-300` — used for PaddleCard, Stats chart panels

Selection colors: `selection:bg-primary/30 selection:text-primary`

Source: `index.css` `:root` block, `Home.tsx`, `PaddleCard.tsx`, `Stats.tsx`, `Chat.tsx`, `BottomNav.tsx`

## Animation Contract

| Element | Animation | Values |
|---------|-----------|--------|
| Hero left column | fade-in + slide from left | `opacity 0→1, x -40→0, duration 0.9s, ease easeOut` |
| Floating paddle image | float loop | `y 0→-14→0, duration 4s, ease easeInOut, repeat Infinity` |
| Paddle entry on mount | spring scale | `opacity 0→1, scale 0.85→1, duration 1.2s, spring damping 20` |
| PaddleCard grid items | staggered fade-up | `opacity 0→1, y 20→0, duration 0.4s, delay index*0.05s` |
| Stat bars (PWR/CTRL/SPIN) | width expand on mount | `width 0→value%, duration 0.6s, ease easeOut` |
| BottomNav active indicator | layout animation | `layoutId="bottom-nav-indicator"` shared element transition |
| Quiz option selection | auto-advance | 300ms delay after selection before step increment |
| Chat messages | fade-in per message | `motion.div` per bubble |
| Primary CTA button | hover/tap micro | `whileHover scale 1.03, whileTap scale 0.97` |
| CTA pulse ring | ambient pulse | `animate-ping bg-primary/30, animationDuration 2.5s` |

Source: `Home.tsx`, `PaddleCard.tsx`, `BottomNav.tsx`, `Quiz.tsx`, `Chat.tsx`

## Layout Contract

| Structure | Spec |
|-----------|------|
| App shell | `min-h-screen bg-background text-foreground relative` — no sidebar, no top nav |
| Navigation | Fixed bottom (`BottomNav`) — 3 items: Home `/`, AI Coach `/recommend`, Análise `/statistics` |
| BottomNav container | `glass-panel mx-4 mb-4 md:mb-6 rounded-2xl max-w-md md:mx-auto` — centered on desktop |
| Page content padding | `container mx-auto px-4` — all pages; `pb-32` for BottomNav clearance |
| Hero | Full-width section, `min-h-[580px]`, 2-column grid on md+ (`md:grid-cols-2`) |
| Catalog grid | `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4 gap-5` |
| Stats KPI row | `grid-cols-2 md:grid-cols-4 gap-4` |
| Stats charts | `grid lg:grid-cols-2 gap-6` |
| Chat | `h-screen flex flex-col` — full viewport height, no scroll on outer container |
| Breakpoints | Tailwind 4 defaults: sm=640px, md=768px, lg=1024px, xl=1280px |
| Max content width | `container` (Tailwind default, centers at xl) |
