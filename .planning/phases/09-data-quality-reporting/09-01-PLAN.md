  <action>
    Create `scripts/quality_aggregator.py` with the following structure:

    **Constants:**
    ```python
    FRESHNESS_THRESHOLD_HOURS = 24.0
    COMPLETENESS_THRESHOLD_PCT = 70.0
    OFFER_REQUIRED_FIELDS = ["price_brl", "url", "store_name", "last_updated"]
    ```

    **Functions:**

    1. `compute_metrics(scraper_name: str, session: Session) -> dict` — Computes all 5 metrics:
       - `freshness_hours`: Query `SELECT MAX(last_updated) FROM market_offers WHERE store_name = :name AND is_active = true`, compute hours since that timestamp. If no rows, return float('inf').
       - `completeness_pct`: Query all active MarketOffer rows for this store_name, for each row check if all OFFER_REQUIRED_FIELDS are non-null and non-empty. Return percentage of rows that are fully complete.
       - `coverage_pct`: For all active MarketOffer rows for this store_name, count total non-null field values across OFFER_REQUIRED_FIELDS / (total_rows * len(OFFER_REQUIRED_FIELDS)) * 100.
       - `product_count`: `SELECT COUNT(*) FROM market_offers WHERE store_name = :name AND is_active = true`
       - `error_rate`: Query `SELECT COUNT(*) FILTER (WHERE status = 'fail') / NULLIF(COUNT(*), 0) FROM quality_metrics WHERE scraper_name = :name AND checked_at > NOW() - interval '24 hours'`. If no prior rows, return 0.0.
       - `status`: "fail" if freshness_hours > 24 OR completeness_pct < 70 OR error_rate > 0.3; else "pass"

    2. `persist_metrics(scraper_name: str, run_id: str, metrics: dict, session: Session) -> QualityMetric` — Creates and commits a QualityMetric row with all fields from the metrics dict + scraper_name + run_id.

    3. `compute_and_persist(scraper_name: str, run_id: str, session: Session) -> QualityMetric` — Calls compute_metrics then persist_metrics. Returns the persisted object.

    4. `consolidate(run_id: str, session: Session) -> dict` — Queries all QualityMetric rows with matching run_id, counts passing/failing, persists a summary row with scraper_name="__consolidated__" containing the aggregate in details JSONB: `{"total": N, "passing": N, "failing": N, "scrapers": {...}}`.

    **CLI (argparse):**
    ```python
    parser = argparse.ArgumentParser(description="Quality metric aggregator")
    parser.add_argument("--scraper", help="Single scraper name")
    parser.add_argument("--all", action="store_true", help="Run for all active scrapers")
    parser.add_argument("--consolidate", action="store_true", help="Consolidate results for this run")
    ```

    - `--all`: Query `SELECT DISTINCT store_name FROM market_offers WHERE is_active = true` to get active scraper list dynamically (same approach as slo_validator.py). Loop and call compute_and_persist for each.
    - `--scraper NAME`: Call compute_and_persist for that single scraper.
    - `--consolidate`: Call consolidate(run_id).
    - `run_id` sourced from `os.getenv("GITHUB_RUN_ID", "manual")`.
    - Uses `init_db_sync()` then `Session(sync_engine)` — same pattern as slo_validator.py.

    - Test persist_metrics calls session.add and session.commit.
    - Test consolidate queries by run_id and returns summary dict.
    - Use `@patch("scripts.quality_aggregator.Session")` pattern matching existing test files.
